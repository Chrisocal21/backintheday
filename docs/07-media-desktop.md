# Media center and family desktop

User scope: all eras, including modern free media. Decades style the physical room and device menus; they do not limit the media catalogue. Preserve separate console libraries and original room movement.

Build a curated backend catalogue with official playable embeds, explicitly marked public-domain films, and clearly labeled external free services. No DRM extraction, arbitrary server URL proxy, or claim that free access grants redistribution rights. Provider names in credits/service links identify the real source; room hardware keeps invented branding. User requested familiar VLC/AIM/iPod behavior: implement an original desktop media player, local buddy-list helper and click-wheel music device. No account integration is implied; Spotify/Apple Music are future connections.

Viewing: Room, TV close-up with room background, screen-only theater, and browser fullscreen. Move the existing playback surface between view containers to preserve a single player and avoid duplicate audio. TV controls remain contextual.

Computer: file explorer desktop, per-PC games, media center, music, tapes, a local notes file, drawing canvas, and an explicitly local helper. Use actual free/open-source game/service links where suitable; don't present commercial classics as free ROMs.
