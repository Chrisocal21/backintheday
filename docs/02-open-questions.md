# Back in the Day - Open Questions

Updated Nov 15, 2026.

## Open
1. VCR tapes: what is on them? Pre-checked YouTube clips, public domain film, or something else?
2. Future game sources: the current five device libraries use 40 original implementations (69 entries). Any external homebrew/freeware additions need verified reuse permission.
3. Grow the listening catalogue: initial sources are Kevin MacLeod / Incompetech (11 CC BY tracks) and LibriVox (23 spoken chapters/acts). Add more verified recordings and era moods.
4. Curated TV channels: which videos per era, all checked for embed support.
5. Distribution: portfolio piece on probablyfinestudios.com, standalone site, or both.
6. Domain: "Back in the Day" is a very common phrase. Check availability; may need a modifier or a studio prefix.
7. Staircase door: stays closed for now. Could lead somewhere later.

## Decided
- Name: Back in the Day, tagline "Feels like home."
- Cozy hangout, no goals
- Four decades in zones with a shared center
- Square basement, stairs along one wall, 70s nook under the stairs
- Stairs provide the skippable player entrance; upstairs remains closed
- React Three Fiber on Vite, not Unity
- Sit mode with free look
- Remote, curated channels, paste-your-own YouTube links
- One TV for videos and games
- Ink-outline room, true-color consoles, normal TV
- GTA-style blended likeness, invented brand names
- Desktop first, gamepad support
- Public domain, homebrew, freeware games only
- Free-to-use music on the record player
- Five v1 interactions (see Handoff)
